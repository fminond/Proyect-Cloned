# Investigación de negocios tipo "intermediario" para Argentina

Este es el espacio de trabajo para buscar modelos de negocio de **plataforma intermediaria**
(como Mercado Libre o Rappi): conectan oferta con demanda, cobran comisión y suman servicios
(pagos, seguro, logística, reputación).

**Qué buscamos:**
1. Modelos que funcionan afuera y **no existen** en Argentina.
2. Modelos que **existen pero están poco desarrollados** acá.
3. Modelos que existen pero admiten una **vuelta de tuerca**.

## Estructura

| Archivo | Para qué sirve |
|---|---|
| [`00-ranking.md`](00-ranking.md) | Tabla con todas las ideas evaluadas y su puntaje. **Empezá por acá.** |
| [`metodologia.md`](metodologia.md) | Criterios de puntaje y plantilla de ficha. |
| [`fichas/`](fichas/) | Una ficha detallada por idea prometedora. |
| [`lecciones.md`](lecciones.md) | Modelos que fracasaron o se complicaron afuera, y qué aprender de ellos. |
| [`combinaciones.md`](combinaciones.md) | Cómo se combinan varias ideas (tesis Vaca Muerta). |
| [`descartadas.md`](descartadas.md) | Ideas que ya están cubiertas en Argentina y el motivo del descarte. Sirve para no repetir búsquedas. |
| [`pendientes.md`](pendientes.md) | Preguntas abiertas y próximos pasos. |
| [`fuentes.md`](fuentes.md) | Links usados en cada ronda. |

## Cómo usarlo desde el celular

Abrí una sesión de Claude Code sobre este repo y pedí, por ejemplo:

- "Hacé una nueva ronda de investigación en `investigacion-negocios`: buscá 5 modelos nuevos de Asia o Europa."
- "Profundizá la ficha de cuidado de mascotas: competidores actuales, precios y un cálculo de cuánto se podría facturar."
- "Validá los pendientes de `pendientes.md`."
- "Agregá esta idea que se me ocurrió: ... y evaluala con la metodología."

Cada ronda se guarda con commit en esta carpeta, así no se pierde nada entre sesiones.

## Advertencia

Esto es investigación de escritorio con fuentes públicas: notas de prensa, sitios de empresas
y tesis. **No reemplaza hablar con clientes reales.** Cada ficha marca lo que hay que validar
en la calle antes de invertir plata.
